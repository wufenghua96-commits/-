# LIN® Portfolio

面向视觉设计师 / AI 设计师 / 品牌设计师 / 视频剪辑的暗色个人作品集网站。

## 启动

```bash
npm install
npm run dev
```

生产构建：`npm run build`

## 内容修改

- 个人信息与项目数据：`src/App.jsx`
- 全局视觉与响应式样式：`src/styles.css`
- 首页背景视频：`public/media/hero-reel.mp4`
- 完整设计开发规范：`DESIGN_SPEC.md`

当前经历与项目文案为可替换示例。拿到完整简历与真实项目素材后，直接替换数据和封面即可。

## 作品图片

从桌面“图片”分类目录导入并压缩后的素材位于 `public/portfolio/`。平面设计、IP 设计和 UI 设计已接入真实作品；AIGC 与动态设计等待后续补充。
